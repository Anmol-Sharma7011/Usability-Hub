# UsabilityHub Clone

A pixel-perfect clone of the UsabilityHub website homepage built with HTML and CSS. View the live site [here](https://anmol-sharma7011.github.io/Usability-Hub/).

## 🚀 Features

- Fully responsive design that works on all devices
- Pixel-perfect recreation of original UsabilityHub homepage
- Interactive components including:
  - Sticky navigation bar
  - Call-to-action buttons
  - Feature cards with hover effects
  - Company logos showcase
  - Testimonial sections
  - Example cards with overlay text
  - Responsive footer

## 🛠️ Built With

- HTML5
- CSS3
- Custom SVG icons
- External image assets
