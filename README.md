# UsabilityHub Clone

A responsive clone of the UsabilityHub website homepage built with HTML and CSS.

## Features

- Fully responsive design
- Modern UI components including:
  - Navigation bar with sign in/up buttons
  - Hero section with call-to-action
  - Company logos showcase
  - Feature cards grid
  - Testimonial sections
  - Example cards with hover effects 
  - Footer with multiple columns
  - Social media links

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins, Roboto)
- SVG icons

## Project Structure

```
├── index.html              # Main HTML file
├── style.css              # CSS styles
├── assets/               # Image assets
│   ├── logos/           # Company logos
│   ├── features/        # Feature icons
│   └── examples/        # Example screenshots
└── README.md
```

## Setup

1. Clone this repository
2. Open index.html in your browser
3. No build process or dependencies required

## Key CSS Features Used

- Flexbox for layouts
- CSS Variables for theming
- Media queries for responsiveness  
- Hover effects and transitions
- Background patterns
- CSS utility classes
